Privacy policy

GPS Debug Tool · Android package com.millerchnz.gpsemulator

Effective 28 September 2026

GPS Debug Tool is a developer utility. It can feed a mock location through Android’s mock-location API, record location fixes on the device, and log Play Services geofence transitions. This policy describes what the app stores and when anything leaves the phone.

Data stored on the device

The app stores the following in app-private storage on your device:

  • Precise location reported by Android: latitude, longitude, accuracy, altitude, speed, bearing, provider, the mock flag, and the other fields the location API returns.
  • Geofences you create, and enter, exit, and dwell events, including the triggering fix.
  • Settings, such as the logging interval, the selected provider, and any webhook URL, extra parameters, or header you enter.
  • A random install id, created on the device the first time it is needed. It is sent only as the device= value on webhook requests, so one phone can be told apart from another.

Logs and these settings are excluded from Android backup and from device-to-device transfer. The developer does not operate a server for this app and does not receive this data.

When data leaves the device

  • Map tiles. The map loads OpenStreetMap tiles over HTTPS from the OpenStreetMap tile servers so it can draw the area on screen. A tile request includes the coordinates of that map view.
  • Webhooks, off by default. If you enter a URL and turn a webhook on, each location row or geofence event is sent as an HTTP GET to the server you named, including the install id. You choose that server. Both http:// and https:// are accepted. A request that fails stays in a queue on the device until it is sent or dropped.
  • Export. If you export or share a CSV or JSON file, that file goes to the app you choose.

Accounts, ads, and analytics

The app has no user accounts. It does not show ads, and it does not include an analytics or crash-reporting SDK.

Deleting your data

Use Clear in the location log or the geofence event log to delete those records. Uninstalling the app deletes everything it stored, including settings and the install id. The developer has no copy of that data. Anything already sent to a webhook server is held by the operator of that server.

Children

GPS Debug Tool is a developer tool aimed at people aged 18 and over. It is not directed at children.
